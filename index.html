Support

Before you contact support, try the FAQ. If you're stuck, use our support form, also linked from the Elevra page in the Shopify Theme Store. Include your store address, the page and section you're working on, and a screenshot. We reply within two business days.

We can help with the theme's own features and settings. We can't make custom code changes, and we can't help with apps or with code someone else added. For custom work, hire a Shopify Partner.

Before you edit theme code yourself, duplicate your theme (Online Store → Themes → ⋯ → Duplicate), so you can always go back. Theme updates don't carry over code edits.

Still stuck?

Send us a message with your store address, the page and section you're working on, and a screenshot. We reply within two business days.
