Product details with metafields

On this page

  • Product badge
  • Shade guides, care instructions and other info panels
  • Complementary products ("Pairs well with")
  • Collection banner
  • Store locations
  • Comparison specs
  • Troubleshooting

Elevra can show extra product information that Shopify doesn't have a field for: a badge, a shade guide, a care panel, products that go well together, a wide collection banner, your store locations and comparison specs. You add this information once in your Shopify admin with metafields (extra fields on a product or collection) and metaobjects (reusable entries, such as one size guide shared by many products). The theme then shows it automatically.

You only need the parts you'll use. Each one below is independent.

Where things are in the admin: metafield and metaobject definitions live in Settings → Custom data. Metaobject entries live in Content → Metaobjects.

Product badge

A short label on the product card, such as "Bestseller" or "Limited edition".

  1. Go to Settings → Custom data → Products → Add definition.
  2. Name: Badge. Namespace and key: custom.badge. Type: Single line text. Save.
  3. Open a product, scroll to Metafields, and type the badge text in Badge. Save.

The badge appears on product cards everywhere (collections, search, home page sections). Its color is set in Theme settings → Product cards → Custom badge color.

Shade guides, care instructions and other info panels

A link on the product page (for example "Shade guide and care") that opens a panel with a title and text. One panel can be shared by many products, so you write your size guide once.

Create the panel type (once):

  1. Go to Settings → Custom data → Metaobject definitions → Add definition.
  2. Name: Info panel. Type (shown under the name): info_panel.
  3. Add two fields: Title (key title, single line text) and Content (key content, rich text). Optionally add Image (key image, file, images only).
  4. Turn on Storefronts access. Save.

Write your panels:

  1. Go to Content → Metaobjects → Info panel → Add entry.
  2. Fill in the title (for example "Finding your shade") and the content. Save. Repeat for each panel (for example "Ingredients and care").

Connect panels to products:

  1. Go to Settings → Custom data → Products → Add definition.
  2. Name: Info panel. Namespace and key: custom.size_guide. Type: Metaobject, and choose Info panel. Save.
  3. Open a product, find Info panel under Metafields, and pick the panel. Save.

Show it on the product page:

  1. In the theme editor, open a product page and click the Product information section.
  2. Add an Info drawer block. Set Link text (what customers click) and Product metafield to custom.size_guide.
  3. Optional: pick a Fallback page to show for products without a panel. Save.

Products without a panel and without a fallback page simply don't show the link. You can add several Info drawer blocks for different metafields (for example a size guide and a care panel).

Complementary products ("Pairs well with")

Products that go well with the one being viewed, shown on the product page and in the cart.

Option A, automatic: install Shopify's free Search & Discovery app, open a product there and choose its complementary products.

Option B, hand-picked in the product:

  1. Go to Settings → Custom data → Products → Add definition.
  2. Name: Complementary products. Namespace and key: custom.complementary. Type: Product, and choose List of products. Save.
  3. Open a product and pick its complementary products under Metafields. Save.

Hand-picked products take priority over the app's. To show them, add a Complementary products block to the Product information section. In the cart, turn on Theme settings → Cart → Products to suggest.

Collection banner

A wide image at the top of a collection page. Without it, the collection's own image is used.

  1. Go to Settings → Custom data → Collections → Add definition.
  2. Name: Banner image. Namespace and key: custom.banner. Type: File, images only. Save.
  3. Open a collection and upload a wide image (at least 2400 × 800 pixels) under Banner image. Save.
  4. In the theme editor, open the collection page and turn on Show collection image in Collection products.

Store locations

Your shops on a "Find a store" page, with address, opening hours, a call button, directions and a search.

Create the store type (once):

  1. Go to Settings → Custom data → Metaobject definitions → Add definition.
  2. Name: Store location. Type: store_location.
  3. Add these fields (key in brackets): Name (name, single line text), Address (address, multi-line text), City (city, single line text), Phone (phone, single line text), Opening hours (hours, multi-line text), Map link (map_url, URL), Image (image, file, images only). Only Name and Address are required.
  4. Turn on Storefronts access. Save.

Add your stores: Content → Metaobjects → Store location → Add entry, one entry per store.

Show them: create a page (Online Store → Pages → Add page, for example "Find a store") and choose the store-locator template. Or add a Store locator section to any page.

If you leave Map link empty, the Directions button opens a map search for the address.

Comparison specs

The Product comparison section can show up to six rows from product metafields, such as battery life or weight.

  1. For each spec, go to Settings → Custom data → Products → Add definition. For example: Name Battery life, namespace and key specs.battery_life, type Single line text.
  2. Fill in the spec on each product under Metafields.
  3. In the theme editor, add a Product comparison section, add the products, and for each row set Row label (for example "Battery life") and Metafield (specs.battery_life).

Empty values show as "Not specified". Specs can also reference a metaobject (for example a "Material" entry); the theme shows its title.

Troubleshooting

  • Nothing shows up: check the namespace and key are typed exactly (for example custom.size_guide, no spaces), the product has a value, and the theme block points to the same namespace and key.
  • A metaobject panel is empty: make sure the metaobject definition has Storefronts access turned on, and that its fields are named title and content.
  • A new metafield doesn't appear on the product: reload the product page in the admin after creating the definition.
